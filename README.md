# 🌾 FarmSafe AI — Smart Farming. Safer Crops. Better Harvests.

FarmSafe AI is a premium, highly interactive **AI-powered agriculture web application** built with HTML5, Vanilla CSS3, and ES6 JavaScript.

---

## 🌟 Key Features

1. **🌿 AI Crop Disease Detection**
   - Drag & drop image upload, live webcam video stream snapshot capture, and pre-loaded sample leaf preset library (Tomato Early Blight, Paddy Bacterial Blight, Potato Late Blight, Cotton Leaf Curl, Maize Rust, Healthy Leaf).
   - Animated laser vision scanner line and progress overlay.
   - AI Confidence Ring Gauge (e.g. 94%, 96%, 92%).
   - Detailed disease diagnosis: symptoms, scientific cause, severity badge, and spread mechanism.
   - Numbered step-by-step "How to Overcome" guide (Step 1 to Step 5).
   - Separate **Organic / Natural Treatment** and **Chemical Spray Guidance** with prominent safety label disclaimers.

2. **🌦️ Weather Intelligence & Agricultural Advice**
   - Live integration with the keyless Open-Meteo API & browser Geolocation.
   - City search for agricultural hubs (Guntur, Vijayawada, Hyderabad, Warangal, Kurnool, Visakhapatnam, Delhi, Punjab, etc.).
   - Live metrics: Temp, Feels Like, Humidity, Wind speed, Rain probability, and UV Index.
   - Dynamic Agricultural Advice generator (Rain expected -> suspend spraying; High heat -> early morning irrigation; High humidity -> fungal disease alert; Strong wind -> halt spraying).
   - Hourly weather forecast timeline (NOW, 3 PM, 5 PM, 7 PM, 9 PM, 11 PM).

3. **🎨 Dynamic Weather Canvas Background Engine**
   - Real-time 60fps canvas particle system adaptively switching themes based on weather:
     - ☀️ **Sunny**: Golden light particles & warm flares.
     - 🌧️ **Rain**: Rain streaks & water splash droplets.
     - ☁️ **Cloudy**: Drifting soft cloud layers.
     - ❄️ **Cold**: Gently falling snow crystals.
     - ⛈️ **Storm**: Dark atmospheric backdrop & lightning flashes.
   - Includes manual theme switcher selector for instant testing!

4. **🤖 Floating AI Farm Assistant Chatbot**
   - Floating action button opening expandable chatbot panel.
   - Preset quick prompt pills (Weather Advice, Crop Health, Treatment, Fertilizer Schedule).
   - Context-aware agricultural question answering in English & Telugu (`తెలుగు`).

5. **🌐 Complete Dual Language System (English + తెలుగు)**
   - Dynamic language switcher (`English | తెలుగు`) in sidebar and header.
   - Translates all UI text, menu items, disease diagnosis details, step remedies, safety warnings, weather metrics, and chatbot replies without page refresh.

6. **📊 Farm Insights & Analytics**
   - Crop Health Ratio charts (Healthy, At Risk, Diseased).
   - Scan History log with timestamped records.

---

## 🚀 Getting Started

Simply open `index.html` in any standard modern desktop or mobile web browser. No complex server setup or npm install required!
